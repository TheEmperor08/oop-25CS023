# MiniBank - Practical 05

Abstract Account with SavingsAccount, CurrentAccount and FixedDepositAccount; run-time polymorphism; pattern instanceof.

This folder is the cumulative MiniBank checkpoint after Practical 05 (it builds on Practical 04). `MiniBank.main` runs this practical's demo, then shows the menu from Practical 01. Choose `6` (EXIT) to quit.

## Compile and run (JDK 17+), from this folder

```
javac -d out src/*.java
java -cp out MiniBank
```

`out/` and `*.jar` are build output and are not committed.
