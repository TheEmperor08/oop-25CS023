# MiniBank - Practical 03

toString(), equals()/hashCode() by account number, static nested Customer.Address, clone(), instanceof.

This folder is the cumulative MiniBank checkpoint after Practical 03 (it builds on Practical 02). `MiniBank.main` runs this practical's demo, then shows the menu from Practical 01. Choose `6` (EXIT) to quit.

## Compile and run (JDK 17+), from this folder

```
javac -d out src/*.java
java -cp out MiniBank
```

`out/` and `*.jar` are build output and are not committed.
