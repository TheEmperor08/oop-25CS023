# MiniBank - Practical 04

Validator (regular expressions), TransactionType enum, Command record, CommandParser, StatementFormatter (StringBuilder).

This folder is the cumulative MiniBank checkpoint after Practical 04 (it builds on Practical 03). `MiniBank.main` runs this practical's demo, then shows the menu from Practical 01. Choose `6` (EXIT) to quit.

## Compile and run (JDK 17+), from this folder

```
javac -d out src/*.java
java -cp out MiniBank
```

`out/` and `*.jar` are build output and are not committed.
